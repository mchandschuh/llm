# Improve llm req -h response

# Details

We require a command to list available llm req <request-name>
as well as support for llm req <request-name> -h to list parameters
required to invoke an llm request.

The goal for this work item is to have great help documentation
for llm req -h [includes resolvable request listing] and
llm req <request-name> -h [includes parameters and how to
set them via the command line along w/ annotations, such as file.
